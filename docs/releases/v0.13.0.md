# FleetLever v0.13.0

FleetLever becomes a single English SaaS: the commercial site and the customer console.

## Discontinued

The Greek public-sector products are removed, not disabled:

- The civic dispatch application, where citizens reported incidents.
- The Elliniko-Argyroupoli employee portal at `/main-page`, and `/worker-apps`, which only forwarded to it.
- The Thessaloniki Improve My City integration behind `/external-blockers`.
- The `elliniko` edition itself. The edition contract is now `console | site`.

The municipal brand lockup, the municipal Lisa assistant, the civic Lisa adapter and the
Elliniko logo assets are gone with them. `verify-edition-config` now fails if any of those
tokens reappear.

## Security

- **Every server action now checks access.** All 23 exported actions in `src/app/actions.ts`
  were reachable without authentication. Server actions are POST endpoints in their own right,
  addressed by an action id that ships in the client bundle, so the page-level session checks
  never covered them. `switchWorkspace` rewrites the active tenant cookies and is now
  super-admin only.
- **The demo login route is deleted.** It issued a super admin session to any caller with no
  credentials. `verify-security-contract` asserts it stays absent.
- **The local super admin session can no longer be granted on a hosted deployment.** It was
  granted whenever `NODE_ENV` was not exactly `production`, so a hosted app started with
  `npm run dev`, or with `NODE_ENV` unset, would have handed super admin to anonymous callers.
- **Session signing is under test for the first time**, covering forged secrets, tampered
  payloads, expired sessions and malformed cookies.
- **Runtime dependency advisories cleared.** `next` 16.2.12, with `postcss` and `sharp`
  overrides expressed as ranges so a stale pin cannot rot into a vulnerability again.
  `npm audit --omit=dev` reports zero.

## English console

576 distinct Greek strings across 1,092 occurrences are now English: navigation, views,
drawers, modals, toasts, seed records and placeholder copy. Dates, numbers and lowercasing
use `en-GB`.

Copilot previously matched questions on Greek keywords only, and its document branch had no
English keyword at all, so an English question about documents could never reach it.

`operations-console.tsx` and `screenshot-carousel.tsx` had no importers anywhere and were
deleted.

## QA

`npm run e2e:smoke` passes for the first time. It had four independent breakages, each hiding
the next: it could not spawn a server on Windows, it bound the wrong port on every platform,
it never authenticated, and its assertions predated the Greek localisation.

`npm run lint` reported 98,991 problems because it walked local worktrees and archives; those
are ignored now, so the QA gate can pass.

## Not included

The commercial site is untouched, including the municipal industry vertical on the landing
page. Municipal fleets are a market everywhere, which is separate from the discontinued Greek
deployments.

The Greek CSV import column aliases and the Greek ranges in the slug regexes are kept. Both
are input-side fallbacks that only widen what a customer can import.
