# FleetLever v0.8.0

Release date: 2026-07-14

## Summary

FleetLever `v0.8.0` separates the municipal review experience, the standalone B2B console, and the commercial website into permanent runtime editions while keeping one maintainable repository.

## Highlights

- Added the `elliniko`, `console`, and `site` runtime editions.
- Added strict route isolation between municipal, B2B, and marketing surfaces.
- Preserved the Elliniko-Argyroupoli employee portal, municipal fleet application, and civic dispatch application.
- Added a standalone FleetLever console with B2B branding, generic construction assets, work packages, staff roles, and isolated persistence keys.
- Reworked the Greek commercial site around the daily readiness decision, real product screenshots, a three-step workflow, and one consistent demo CTA.
- Reworked pricing around a 30-day paid pilot followed by two explicit operating plans.
- Added static contracts, route-matrix checks, and desktop/mobile Playwright verification.
- Added separate Railway service identities and tenant-scoped municipal data.

## Deployment Notes

- No custom domains are included in this release.
- All Railway services deploy from `main`.
- The commercial site skips database migrations.
- Elliniko uses a dedicated organization/profile tenant pair in the shared Railway Postgres instance.
